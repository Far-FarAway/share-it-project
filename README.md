# Share It

Приложение для поиска и бесплатной аренды вещей.

Пользователи могут публиковать посты с вещами, которые они готовы одолжить на время, искать нужные вещи по фильтрам и непосредственно арендовать вещи других людей. Также те, кто воспользовался вещью или в процессе пользования может оставить отзыв на нее.

Стек технологий: java, spring boot, hibernate, maven, postgreSQL, docker, postman.
